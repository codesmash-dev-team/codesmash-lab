ข้อมูลสุขภาพอยู่ในแอปสุขภาพที่เดียว

ปรับปรุงล่าสุด 1 ตุลาคม 2026

CodeSmash Lab เป็นแอปเกมบน iPhone ที่ชวนให้ขยับตัวผ่านข้อมูลจากแอปสุขภาพ แอปไม่มีบัญชีผู้ใช้ ไม่มีโฆษณา ไม่มีระบบวิเคราะห์การใช้งาน (analytics) และไม่ติดตามข้ามแอปหรือเว็บไซต์อื่น ข้อมูลสุขภาพและประวัติการเล่นไม่ถูกส่งออกจากเครื่อง

ข้อมูลที่อ่านจากแอปสุขภาพ

เมื่อให้สิทธิ์ แอปอ่านข้อมูลต่อไปนี้มาแสดงเป็นภารกิจ ตัวเลข และสถิติในแท็บสุขภาพ

  • จำนวนก้าว
  • ระยะทางเดินและวิ่ง
  • จำนวนชั้นที่ขึ้น
  • เวลาออกกำลังกาย
  • การนอน
  • อัตราการเต้นของหัวใจ
  • อัตราการเต้นของหัวใจขณะพัก
  • ความแปรปรวนของอัตราการเต้นของหัวใจ (HRV)
  • อัตราการเต้นของหัวใจเฉลี่ยขณะเดิน
  • ความมั่นคงในการเดิน
  • workout และเส้นทางของ workout

แอปให้แอปสุขภาพแจ้งเมื่อจำนวนก้าวเปลี่ยน แม้ตอนที่ไม่ได้เปิดแอปอยู่ เพื่อให้ภารกิจของวันเป็นปัจจุบัน ข้อมูลที่อ่านมาใช้แสดงบนหน้าจอเท่านั้น แอปไม่เก็บสำเนาไว้เองและไม่ส่งออกนอกเครื่อง

ข้อมูลที่เขียนลงแอปสุขภาพ

เมื่อจบการเดินที่กดเริ่มในแอป แอปบันทึกการเดินนั้นเป็น workout พร้อมเส้นทางและผลตรวจลงแอปสุขภาพ ส่วนระยะทางบันทึกเฉพาะการเดินที่ผ่านการตรวจ ทั้งหมดนี้ทำเฉพาะเมื่อให้สิทธิ์เขียนไว้ แอปไม่แก้และไม่ลบข้อมูลอื่นในแอปสุขภาพ การเดินที่บันทึกแล้วดูและลบได้ในแอปสุขภาพ

ตำแหน่งและการเคลื่อนไหว

แอปใช้ตำแหน่งและการนับก้าวของ iPhone เฉพาะระหว่างการเดินที่กดเริ่มเอง รวมถึงตอนล็อกจอหรือสลับไปแอปอื่นระหว่างการเดินนั้น เพื่อตรวจว่าเป็นการเดินจริง แอปขอสิทธิ์ตำแหน่งแบบ "ขณะใช้แอป" เท่านั้น และไม่ใช้ตำแหน่งตอนที่ไม่ได้เดิน การเดินที่ยังไม่จบไม่ถูกเขียนลงเครื่อง

ข้อมูลที่เก็บในเครื่อง

  • ประวัติการเล่นเกม: เกมที่เล่น เล่นกี่ครั้ง นานเท่าไร และเล่นล่าสุดเมื่อไร
  • ความสำเร็จที่ปลดล็อกแล้ว
  • รายการในกล่องการแจ้งเตือนของแอป และการตั้งค่าการแจ้งเตือน
  • รูปโปรไฟล์หรือตัวละครที่เลือก
  • รายชื่อเกมและภาพปกชุดล่าสุดที่โหลดมา

ข้อมูลเหล่านี้อยู่ในพื้นที่ของแอปบน iPhone และไปกับข้อมูลสำรองของเครื่อง (iCloud หรือคอมพิวเตอร์) ตามการตั้งค่าของเครื่อง ไม่ถูกส่งมาให้เรา

การเชื่อมต่ออินเทอร์เน็ต

เมื่อเปิดแอป แอปโหลดรายชื่อเกม คำอธิบาย และภาพปก จากเซิร์ฟเวอร์ Game Center ของ CODESMASH (center.game.gamification.in.th) คำขอนี้ไม่มีข้อมูลสุขภาพ ประวัติการเล่น หรือรหัสที่ระบุตัวผู้ใช้หรือเครื่อง เซิร์ฟเวอร์เห็นแค่ข้อมูลการเชื่อมต่อทั่วไปของอินเทอร์เน็ต เช่น IP address

เกมแต่ละเกมเป็นหน้าเว็บที่โหลดจากอินเทอร์เน็ตมาเปิดในแอป แอปไม่ส่งข้อมูลสุขภาพหรือประวัติการเล่นให้เกม ผู้ให้บริการโฮสต์ของหน้าเว็บเกมเห็นข้อมูลการเชื่อมต่อทั่วไปแบบเดียวกัน และหน้าเว็บของเกมอาจจำความคืบหน้าในเกมไว้ในเครื่องตามปกติของเว็บ

สิทธิ์ที่แอปขอ

  • แอปสุขภาพ อ่านและเขียนตามรายการข้างบน
  • ตำแหน่ง (ขณะใช้แอป) ระหว่างการเดินที่กดเริ่มเอง
  • การเคลื่อนไหวและฟิตเนส นับก้าวระหว่างการเดิน
  • การแจ้งเตือน แอปสร้างการแจ้งเตือนในเครื่องเอง เช่น เตือนตอน 20:00 ในวันที่ยังไม่ครบเป้า หรือเมื่อได้ความสำเร็จใหม่ ไม่มีเซิร์ฟเวอร์ส่งการแจ้งเตือนมา
  • รูปภาพ เลือกรูปจากคลังมาเป็นรูปโปรไฟล์ รูปที่เลือกถูกคัดลอกไว้ในพื้นที่ของแอปและไม่ถูกอัปโหลด

Apple Watch และ Live Activity

แอป CodeSmash Lab บน Apple Watch ใช้เริ่ม พัก และจบการเดินจากข้อมือ โดยคุยกับ iPhone ที่จับคู่ไว้โดยตรง ระหว่างเดิน ความคืบหน้าขึ้นบนหน้าจอล็อกและ Dynamic Island ผ่าน Live Activity ซึ่งอัปเดตจากในเครื่อง ไม่ผ่านเซิร์ฟเวอร์

การลบและควบคุมข้อมูล

  • ถอนสิทธิ์ตำแหน่ง การเคลื่อนไหวและฟิตเนส การแจ้งเตือน และรูปภาพได้ทุกเมื่อในแอปตั้งค่า ที่หัวข้อ CodeSmash Lab
  • สิทธิ์ของแอปสุขภาพและการเดินที่แอปบันทึกไว้ จัดการได้ในแอป Health แตะรูปโปรไฟล์ แล้วหาหัวข้อเกี่ยวกับแอป
  • ลบแอปเพื่อลบทุกอย่างในพื้นที่ของแอป ส่วนการเดินที่บันทึกลงแอปสุขภาพแล้วยังอยู่ในแอปสุขภาพจนกว่าจะลบที่นั่น

เว็บไซต์นี้

เว็บไซต์นี้เป็นหน้าเว็บนิ่ง ไม่มีสคริปต์ ไม่มีแบบฟอร์ม ไม่มีตัวนับ และไม่โหลดอะไรจากเว็บอื่น ฝากไว้บน GitHub Pages ซึ่งอาจบันทึกข้อมูลทางเทคนิคของคำขอ เช่น IP address ตามนโยบายของ GitHub
